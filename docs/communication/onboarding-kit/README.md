# Citizen onboarding kit

Copy a municipality publishes under its own name to tell residents how to report a problem and how to follow what happens next. Every file is bilingual: English first, then the full Croatian version.

The kit describes one loop, in this order:

1. A resident reports a problem.
2. The municipality names the office responsible.
3. That office files a commitment: what it will do and by when.
4. An independent reviewer checks the evidence. The office cannot mark its own work done.
5. A public receipt is published and anyone can read it.

Residents file through a widget on the municipality's existing website. The kit never asks them to learn a new system.

## How to use it

1. Replace the placeholders. There are three:

   | Placeholder | Croatian | Replace with |
   | --- | --- | --- |
   | `[Municipality]` | `[Općina]` | The name of the municipality, as it appears on official notices. |
   | `[category]` | `[kategorija]` | One report category residents recognise, used as the example in the copy. |
   | `[web address]` | `[web adresa]` | The page on the municipality's site that holds the report form and the public records. |

   The Croatian placeholders are written in the nominative. Some sentences will need the case adjusted once the real name is in place.

2. Read every line against your own process. If your office cannot do what a line promises, cut the line. Do not add numbers, deadlines, or results you cannot show.
3. Publish under the municipality's name, on the municipality's channels. Publish only once residents can actually file a report at `[web address]`.

## What each file is for

| File | Use |
| --- | --- |
| `explainer.md` | Script for a 60-second video. Numbered shots, each with the on-screen visual and the voiceover line. |
| `social-posts.md` | Three posts for the municipality's Facebook page: the announcement, how a resident knows a report is done, and how to file step by step. |
| `how-to-report.md` | One-page flyer, "Kako prijaviti problem". For the notice board, the counter, and print. Includes a marked spot for a QR code. |

## Claims the copy is allowed to make

- Every report gets a public record.
- Nothing is marked done until an independent check confirms it.
- A resident can look up the status of their report at any time.
- The record shows which office is responsible and what was promised.

## Limits the copy has to keep

- The resident's name, contact details, and the text of their case are not published. Say so plainly wherever a resident might assume otherwise.
- A record is not a repair. It shows who owns the problem and what was promised, not that the problem is fixed.
- An independent check compares the evidence with what was promised. It does not judge whether the promise was the right one.
- No invented statistics, no quotes from residents who do not exist, no claims about how much faster anything is.
