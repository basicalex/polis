# Governance

This repository is governed as public-interest infrastructure. The default decision rule is: protect citizens and evidence integrity before optimizing institutional convenience.

## Maintainer duties

- Keep documentation accurate about implemented and mocked capabilities.
- Require evidence for public civic claims.
- Reject changes that weaken private-document separation, auditability, or AI review state.
- Keep security and privacy regressions release-blocking.
- Record material architecture or policy decisions in durable project memory or ADRs when introduced.

## Partner duties

Partners piloting Polis Interface must define purpose, jurisdiction, data categories, retention, review roles, escalation paths, publication rules, and rollback conditions before using real data.

## Change policy

Material changes to proof semantics, evidence scoring, AI behavior, reward rules, access control, retention, or audit visibility require explicit review and updated documentation.
